Supplementary tables and patterns for [SKILL.md](SKILL.md). English and Chinese materials live in separate sections; each section stays in one language.

| Original | Replace with |
|---|---|
| utilize | use |
| demonstrate | show |
| facilitate | help |
| approximately | about |
| in order to | to |
| due to the fact that | because |
| despite the fact that | even though |
| with regard to | about, concerning |
| a number of | several, many |
| a majority of | most |
| at this point in time | now |
| has the ability to | can |
| in the event that | if |
| for the purpose of | to, for |

| subsequent to | after |
| conduct an investigation into | investigate |

Exceptions:

- Keep "demonstrate" when it means "prove", as in proving a theorem.

## Hyphen decisions

Replace — ornamental compounds with a plain equivalent:

- state-of-the-art → advanced, current best
- high-quality → good, strong, by context
- user-friendly → easy to use
- highly-accurate → accurate

Keep — standard terms and fixed collocations:

- long-term, short-term
- non-parametric, t-test
- COVID-19

Keep — compound modifiers that prevent ambiguity:

- high-resolution imaging
- small-sample bias

## Clause-splitting triggers (English)

- Split when one sentence contains two or more relative pronouns or connectors (that, which, where, who).
- Split when a relative clause carries a second, independent idea.

Before:

> X, which was proposed in 2020 and has since become standard, achieves Y.

After:

> X was proposed in 2020 and has since become standard. It achieves Y.

## 中文替换表

| 原表达 | 替换为 |
|---|---|
| 进行了……的分析 / 研究 / 探讨 | 分析 / 研究 / 探讨了…… |
| 对……进行了探讨 | 探讨了…… |
| 在……方面 | 在……上、关于…… |
| 存在着…… | 有…… |
| 仍存在着一定的局限性 | 仍有局限 |
| 诸多 | 许多 |
| 实现了对……的提升 | 提升了…… |
| 基于……的考虑 | 考虑到……、因为…… |
| 具有重要的意义 | 很重要 |
| 起到了……的作用 | 直接写出动作，如"促进了增长"，不写"起到了促进增长的作用" |

## 长句拆分

名词短语中"的"字连用超过两个时，在自然断点处拆句，并重复中心词。

改写前：

> 我们提出了一种基于对大规模数据的系统分析的方法。

改写后：

> 我们提出了一种新方法。该方法对大规模数据进行系统分析。

## Connectors for split sentences

English: therefore, however, in addition, but, thus, as a result, in contrast.

中文：因此、然而、此外、但是、不过、由此可见、相比之下。
