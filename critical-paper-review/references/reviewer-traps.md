# Reviewer traps and three lenses

Run this **after** the dimension pass, before mapping the score. Distilled from ARS review-quality thinking and common-review-pitfalls list.

## Three lenses

1. **Internal validity.** Central claim → evidence → warrant. Would removing one unreplicated piece collapse the argument? If yes, say so (often G3 or G2).
2. **External validity.** Compare claimed scope to the sample, the theorem's assumptions, or the benchmark. If the claims already match the evidence's scope, there is no finding.
3. **Contribution.** What was known, what is known after, is the delta meaningful for the stated audience. If you cannot state the delta in one sentence, either Originality is weak or Clarity is. Decide which, with a quote.

## Traps (self-check)

| Trap | Test |
| :--- | :--- |
| Hypercriticism | Did I acknowledge at least one genuine strength I actually found? Did I turn copyediting into a reject? |
| Novelty bias | Am I punishing a replication or a negative result that the evidence supports? |
| Prestige bias | Would the same manuscript from an unknown group get the same labels? |
| Method tunnel | Did I skip "so what?" and only list protocol nits? |
| Preference projection | Am I requiring my favourite method rather than asking whether theirs answers their question? |
| Language discrimination | Am I scoring Clarity `DOES_NOT_MEET` for non-native phrasing when meaning is clear? If yes, relabel. |
| Positivity-severity split | Did I write a kind letter and then dump a 3? Labels first, prose second. |
| Forest vs trees | Is the first finding the load-bearing one? |

## Calibration questions (not a second score)

1. If published as-is, would it mislead readers? If yes, the recommendation class should not be accept-side unless that misleading piece is presentation-only.
2. Could the authors address the decision-bearing findings in one revision cycle? If no, reject-side is more honest than "major".
3. Am I harsher than I would be on my own work?
4. Did I manufacture a strength I did not find?

Clarity defects still cannot raise the scientific score and can lower it by at most 1.
